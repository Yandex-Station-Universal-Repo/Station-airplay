# Сторонние компоненты и релизная проверка

Исходные Avahi0.7 и часть ARMhf-библиотек взяты из прежнего пакета Plum; полная воспроизводимость этих исходных компонентов остаётся ограничением upstream. Shairport/NQPTP обновлены в существующих путях; отдельный приёмник нужен только для AArch64 ALSA. Текущие версии/исходники/сборка: [NOTICE.md](NOTICE.md), [third_party](../third_party/README.md), [BUILD.md](../source/BUILD.md).

- Shairport Sync — GPL-3.0; см. `LICENSES/GPL-3.0.txt`.
- Avahi — LGPL-2.1/GPL-2.0 (зависит от компонента); см. `LICENSES/`.
- NQPTP и остальные библиотеки имеют собственные условия: уточните по соответствующим upstream-репозиториям и пакетам сборки.

**До публичного бинарного релиза** проверьте списки лицензий для каждого распространяемого файла, корректность атрибуций и предоставьте соответствующие исходники, патчи и инструкции воспроизводимой сборки там, где это требуется лицензией. Этот репозиторий не содержит полного дерева исходников сторонних программ и не утверждает, что эти требования уже выполнены.
