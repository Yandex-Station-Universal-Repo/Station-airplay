# Поддержка разных Яндекс Станций

Проект ориентирован на линейку устройств, но текущая реализация содержит **Plum-специфичные** предположения:

1. Проверка модели `plum` или `yandexplum` в `verifyYAM`.
2. Четыре разряда сегментов `A..G` с индексами `0..3`, разделитель `DH/DL`.
3. Ровно три RGB-зоны.
4. ALSA `hw:0,0`, 48 kHz S16, файл `/etc/asound.conf` и `pcm.speakers`.
5. ARMv7/armhf готовые `bin/` и `lib/`; жёстко заданные FIFO, проверка quasar-процессов и порта 7000.
6. Стартовые скрипты подготовки хоста рассчитаны на Plum и **не предназначены для других моделей**.

## План адаптации

- Абстрагировать renderer по устройству: без дисплея, часы Mini 2, Midi, Plum.
- Получать количество LED и возможности от YAM `/device`, строить соответствующие кадры.
- Выделить конфигурацию ALSA и аудиопортов в проверяемый profile.
- Выпускать отдельные `.yap` для разных CPU/ABI при необходимости.
- Добавить интеграционные тесты и таблицу реальных проверок.
- Рассмотреть API кнопок и синхронизацию громкости отдельно после проверки возможностей YAM/Shairport Sync.

Документация YAM по API и различиям сегментов: https://github.com/nyakokitsu/yam/blob/main/docs/PLUGIN_API.md

Не снимайте ограничения `plugin.toml` ради установки на неподдерживаемое устройство: успешная установка не означает работоспособность.
