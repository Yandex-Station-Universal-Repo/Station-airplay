# Поддержка разных Яндекс Станций

Предлагаемое расширение добавляет точный `yandexmini_2` и явный `--shared-audio`
для `plum`/`yandexplum`: общий PCM `speakers` без часов и RGB, при этом профиль
по умолчанию (`plug:dmix_spk` с часами и 3 RGB) не меняется. Комната берётся из
общего YAM `device.room`, а не из model override.
[Профили/фактические проверки](SHARED_MODELS.md), [комнаты](ROOMS.md).

Проект ориентирован на линейку устройств, но backend AirPlay 2 для Plum содержит **Plum-специфичные** предположения:

1. Проверка модели `plum` или `yandexplum` в `verifyYAM`.
2. Четыре разряда сегментов `A..G` с индексами `0..3`, разделитель `DH/DL`.
3. Ровно три RGB-зоны.
4. Рабочий профиль Лайт 2 — общий `plug:dmix_spk`, 48 kHz S16. Визуализатор читает копию PCM из FIFO; в динамики идёт тот же поток, не эксклюзивный `hw:0,0`.
5. ARMv7/armhf готовые `bin/` и `lib/`; жёстко заданные FIFO, проверка quasar-процессов и порта 7000.
6. Стартовые скрипты подготовки хоста рассчитаны на Plum и **не предназначены для других моделей**.

## План адаптации

- Абстрагировать renderer по устройству: без дисплея, часы Mini 2, Midi, Plum.
- Получать количество LED и возможности от YAM `/device`, строить соответствующие кадры.
- Выделить конфигурацию ALSA и аудиопортов в проверяемый profile.
- Выпускать отдельные `.yap` для разных CPU/ABI при необходимости.
- Добавить интеграционные тесты и таблицу реальных проверок.
- Рассмотреть API кнопок и синхронизацию громкости отдельно после проверки возможностей YAM/Shairport Sync.

Документация YAM по API и различиям сегментов: https://github.com/nyakokitsu/yam/blob/main/docs/PLUGIN_API.md

Не снимайте ограничения `plugin.toml` ради установки на неподдерживаемое устройство: успешная установка не означает работоспособность.

## Профили 1.3.0

`source/profiles.go` выбирает точную модель YAM. Для Станции 2 и Мини 3 Про используются отдельные ABI receiver и проверенные shared ALSA PCM; clock/RGB не требуются и не вызываются. Запуск, stop, enable/disable и логи принадлежат YAM. Прежняя Plum-ветка сохранена; ограничения выше описывают её AirPlay2 renderer. [Миграция и проверки](SHARED_MODELS.md), [инструкция для новых вкладов](../CONTRIBUTE.md).

Оба shared-профиля используют AirPlay 2 (Shairport 5.6.2 / NQPTP 1.2.9),
48 кГц/S16_LE и объявление HomePod. [ABI, сборка и границы возможностей](AIRPLAY2.md).
