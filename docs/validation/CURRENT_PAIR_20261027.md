## Проверено на хосте

Все три PR YAM отдельно: Rust fmt/check/test, shell syntax, профильные
фикстуры. Интеграция: 18 Rust-тестов, room API/CLI/persistence,
speech API/auth/token revocation, fixture миграции enabled/services,
stop/start/disable/enable и повторного запуска daemon. ARM64 musl build и
воспроизводимость из чистого экспорта подтверждены.

Первый интеграционный прогон с общим кэшем Cargo был отвергнут: использовался
бинарник предыдущей ветки, что поймала фикстура комнат. Все ветки затем
перепроверены с очисткой артефактов самого YAM между ними. Этот отклонённый
прогон не считается PASS и его бинарник на колонки не устанавливался.

## Установлено на устройства

Одинаковые AirPlay и YAM с указанными хешами установлены на Mini 2, обе Lite 2
и Station 2. Сняты бэкапы, проверены хеши; автозапуск AirPlay переведён на
учёт служб YAM 0.1.18 (`services.json`, `service_enabled=true`). Локальный
запускной адаптер использует штатный API enable/disable службы, не второй
супервизор. Состав включённых пакетов и исходные конфиги не изменились.
Проверены процессы, TCP 5000/UDP 9000 и API управления AirPlay.
Защищённое состояние Алисы/Jarvis, нативная громкость и rootfs ro сохранены.

## Границы приёмки

- На прежнем companion YAM 0.1.17 владелец подтвердил полный прогон Mini 2.
  На Lite 2 без часов остальной прогон успешен, но возврат LED провалился;
  на Lite 2 с часами отдельно подтверждён тот же дефект, часы работали.
  На Station 2 отдельно проверено отсутствие этого дефекта, не полный прогон.
- LED-фикс на предыдущей интеграции `ac06313` (yamd `31845804…`) принят
  владельцем на одной Lite 2 без часов после повторных сеансов AirPlay.
  Эту приёмку не переносим на новый YAM 0.1.18 автоматически.
- **На текущей паре ещё ожидаются холодная загрузка, полный индивидуальный
  прогон всех четырёх (включая возврат LED) и групповые тесты.**
- Peer-мост групповой громкости пока выключен в приватном конфиге.
  Multiroom отправителя и наш peer-мост — разные проверки.
- Длительный soak, ARM64 controls, legacy Plum/Midi regression и
  лицензирование/relink-аудит остаются отдельными гейтами публикации.
