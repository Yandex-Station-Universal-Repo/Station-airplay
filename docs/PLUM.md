# Установка на Станцию Лайт 2 (Plum)

Только для подготовленного экспериментального устройства с YAM. `yam` выполняется **на компьютере**; `yamd` работает **на Станции**. Никакого `/opt/yam` на устройстве инструкция не предполагает.

```sh
yam install assets/station-airplay-1.1.5.yap
yam enable station-airplay
yam ps
```

Скрипты `support/prepare-host.sh` и `support/restore-host.sh` — отдельная, потенциально опасная ручная процедура, которую следует изучить до запуска. Они не должны выполняться автоматически и **не предназначены для других моделей**.

Если прежний AirPlay-приёмник ещё запущен, остановите его **перед** включением YAM-плагина. С 1.4.2 Лайт 2 играет в штатный `plug:dmix_spk` рядом с Алисой. Часы и 3 RGB забирает YAM на всё время работы службы и возвращает кадр часов при остановке. Имя приёмника — `Yandex Station Light 2 AirPlay`.
