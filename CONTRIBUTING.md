# Contributing

Пожалуйста, прикладывайте модель, профиль YAM и способ воспроизведения проблемы. Новые устройства должны добавляться отдельными профилями с тестами, а не отключением проверки совместимости. Для Go-кода запустите `go test ./...` и `go vet ./...` в `source/`. Не коммитьте персональные токены, логи с секретами и несогласованные сторонние бинарники.

Полный маршрут для владельцев и ИИ-агентов: [CONTRIBUTE.md](CONTRIBUTE.md). Добавляйте модель в общий плагин с точными ABI/PCM, тестами, доказательствами и откатом.
