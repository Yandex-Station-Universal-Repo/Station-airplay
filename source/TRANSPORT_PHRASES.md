# Карта голосового транспорта AirPlay

Всего 3732 точных вариантов. Источник: `source/transport_dictionary.json`.

Только при живой сессии AirPlay. Не поиск ключевых слов: отрицания,
посторонние запросы и составные команды остаются Алисе.

К вариантам ниже добавлены «пожалуйста» до/после, обращение «Алиса».
Для переключения также есть формы «включи», «поставь», «переключи»,
«давай», «включи мне», «поставь мне», «переключи на», «перейди на»;
для прошлого трека — также «верни». Перечень конечный, не все
возможные естественные формулировки. Неизвестные фразы не перехватываются.

Previous = два назад, 350 мс; Restart = одно назад, без repeat mode.
В начале песни результат назад зависит от плеера отправителя.
