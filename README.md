# Station AirPlay

**AirPlay для Яндекс Станций через [YAM](https://github.com/nyakokitsu/yam).**

Независимый экспериментальный проект, цель которого — дать совместимым Яндекс Станциям возможность принимать музыку по AirPlay (версия протокола зависит от профиля). Проект не связан с Яндексом или Apple. Плагин работает под управлением демона `yamd` на колонке; `yam` — клиентская утилита на компьютере.

> **Версия 1.4.5:** один компактный YAM-плагин с AirPlay 2 для Лайт 2, Лайт, Миди, Станции 2, Мини, Мини 3 и Мини 3 Про. На Лайт 2, Лайт, Станции 2, Мини, Мини 3 и Мини 3 Про звук общий с Алисой. Лайт 2 при этом забирает часы и 3 RGB через YAM. Результаты: [SHARED_MODELS.md](docs/SHARED_MODELS.md).

> **Исторический статус 1.1.5:** доступен проверенный на уровне сборки и пользовательского воспроизведения релиз **v1.1.5 для Яндекс Станции Лайт 2 (Plum)**. Это **не универсальный релиз для всех Станций**. Архитектура проекта рассчитана на расширение поддержки моделей, но перенос на другое оборудование требует отдельной адаптации аудиовыхода, библиотеки и индикации.

## Возможности

- Приём аудио по AirPlay 2 через Shairport Sync и NQPTP.
- Отображение часов, паузы и громкости, а также музыкального визуализатора на совместимом сегментном дисплее.
- RGB-индикация через документированный API YAM; обновление экрана при изменениях до 20 раз в секунду (цель, не гарантия).
- Имя приёмника зависит от профиля: `Yandex Station Light 2 AirPlay`, `Yandex Station Lite AirPlay`, `Yandex Station 2 AirPlay`, `Yandex Station Mini AirPlay`, `Yandex Mini 3 AirPlay`, `Yandex Mini 3 Pro AirPlay`. Миди объявляется как `Я.Станция`.
- Сервисный режим YAM с управлением жизненным циклом дочерних процессов.

**Не реализовано:** управление аппаратными кнопками, обратная синхронизация громкости с телефоном, универсальные аудиобэкенды, нативная медиапанель Apple Home. Это задачи дальнейшей разработки, а не функции v1.1.5.

| Мини 3 Про (`yandexmini_3_pro`) | 5.6.2 / AArch64, общий `speakers` | Не управляет | .50, Алиса сохраняется |
| Мини 3 (`bergamot`) | 5.6.2 / ARMhf, общий `speakers` | Не управляет | .50, Алиса сохраняется |

Clock/RGB ведут Лайт 2 и Миди. Лайт, Станция 2, Мини, Мини 3 и Мини 3 Про индикацию не
занимают. Новые модели не добавляйте в allowlist без проверки ABI, PCM и
функций на устройстве.

## Установка готовой сборки (Лайт 2)

Для Станции 2/Мини 3 Про используйте [отдельную инструкцию миграции](docs/SHARED_MODELS.md) и универсальный архив по [AIRPLAY2.md](docs/AIRPLAY2.md). Архив `assets/station-airplay-1.1.5.yap` ниже — прежний релиз только для Plum.

1. Установите [YAM](https://github.com/nyakokitsu/yam) по официальной инструкции. Клиент `yam` запускается **на компьютере**, `yamd` — на Станции.
   YAM 0.1.18 по умолчанию запрещает binary-пакеты, а station-airplay — binary-пакет. Откройте `http://<колонка>:8099` и включите «Разрешить бинарники плагинов» (в `settings.toml` это `allow_plugin_binaries = true`). Иначе запуск завершится ошибкой `binary execution disabled by administrator`.
2. При необходимости подготовьте аудиоокружение устройства по [инструкции для Лайт 2](docs/PLUM.md). Скрипты подготовки изменяют системную конфигурацию и не запускаются автоматически.
3. Установите готовый .yap из ypkg репозитория средствами YAM:

   ```sh
   yam install station-airplay
   yam service enable station-airplay   # автозапуск и запуск сейчас
   yam service list
   ```

4. Найдите в меню AirPlay устройство **`Yandex Station Light 2 AirPlay`**. Устройство и компьютер/телефон должны быть в сети, допускающей mDNS.

> Существующий независимый AirPlay-сервис или голосовой сервис колонки может занимать аудиоустройство/сетевые порты. Не запускайте две реализации одновременно. При любых ошибках сначала ознакомьтесь с [диагностикой](docs/TROUBLESHOOTING.md).

## Сборка из исходников

Для Go-супервизора требуется Go 1.23+; для упаковки — Python 3.8+. Полная сборка обеих архитектур и namespace helper: [source/BUILD.md](source/BUILD.md). Текущие сборочные скрипты и границы происхождения описаны в инструкции.

```sh
cd source
go test ./...
go vet ./...
GOOS=linux GOARCH=arm GOARM=7 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w' -o ../bin/station-airplay .
cd ..
./scripts/package.sh
```

Архив будет создан в `dist/station-airplay-1.4.1.yap`. Перед публикацией проверьте зависимости и происхождение бинарников: [THIRD_PARTY.md](docs/THIRD_PARTY.md).

## Как это устроено

AirPlay-клиент → Shairport Sync → ALSA-выход + PCM FIFO → Go-сервис → YAM Runtime API → дисплей / RGB. Отдельно Avahi публикует сервис по mDNS, а NQPTP участвует в синхронизации AirPlay 2. Никакие аппаратные GPIO/LED-регистры плагин напрямую не изменяет.

## Отказ от гарантий

Используется на свой риск. Настройка модифицированной Станции и замена штатных служб могут нарушить работу устройства. Делайте резервную копию до изменений.

Иконки AirPlay: Станция 2 и Миди — HomePod; Мини, Мини 3, Мини 3 Про, Лайт и Лайт 2 — HomePod mini. Таблица идентификаторов и правила для новых моделей: [CONTRIBUTE.md](CONTRIBUTE.md#иконки-airplay-модель-объявления).

Версия 1.4.0 объединяет Shairport и сетевые службы, удаляет параллельные runtime и лишние зависимости; все модели используют движок5.6.2. Основной результат сборки — один универсальный `.yap`, один ID в YAM. Исходники и документация находятся в репозитории; на колонку входят runtime и уведомления о лицензиях.
