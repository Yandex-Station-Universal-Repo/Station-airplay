# Station AirPlay

**AirPlay для Яндекс Станций через [YAM](https://github.com/nyakokitsu/yam).**

Независимый экспериментальный проект, цель которого — дать совместимым Яндекс Станциям возможность принимать музыку по AirPlay (версия протокола зависит от профиля). Проект не связан с Яндексом или Apple. Плагин работает под управлением демона `yamd` на колонке; `yam` — клиентская утилита на компьютере.

> **Версия 1.3.0:** один YAM-плагин с AirPlay 2 для Лайт 2, Станции 2 и Мини 3 Про. На Станции 2/Мини 3 Про — Shairport Sync 5.6.2, NQPTP 1.2.9 и совместный звук с Алисой. Новые профили не управляют RGB/часами. Результаты аппаратных проверок: [SHARED_MODELS.md](docs/SHARED_MODELS.md).

> **Исторический статус 1.1.5:** доступен проверенный на уровне сборки и пользовательского воспроизведения релиз **v1.1.5 для Яндекс Станции Лайт 2 (Plum)**. Это **не универсальный релиз для всех Станций**. Архитектура проекта рассчитана на расширение поддержки моделей, но перенос на другое оборудование требует отдельной адаптации аудиовыхода, библиотеки и индикации.

## Возможности

- Приём аудио по AirPlay 2 через Shairport Sync и NQPTP.
- Отображение часов, паузы и громкости, а также музыкального визуализатора на совместимом сегментном дисплее.
- RGB-индикация через документированный API YAM; обновление экрана при изменениях до 20 раз в секунду (цель, не гарантия).
- Имя приёмника зависит от профиля: `Я.Станция` для Plum, `Yandex Station 2 AirPlay` / `Yandex Mini 3 Pro AirPlay` для новых моделей.
- Сервисный режим YAM с управлением жизненным циклом дочерних процессов.

**Не реализовано:** управление аппаратными кнопками, обратная синхронизация громкости с телефоном, универсальные аудиобэкенды, нативная медиапанель Apple Home. Это задачи дальнейшей разработки, а не функции v1.1.5.

## Совместимость

| Модель / группа | Приём AirPlay | Дисплей / RGB | Статус |
| --- | --- | --- | --- |
| **Яндекс Станция Лайт 2 (Plum)** | Реализован | 4-разрядный сегментный дисплей, 3 RGB-зоны | Проверка пользователем: музыка и визуализатор работают |
| Станция Мини 2 | Не проверено | Иная схема сегментов | Требуется аппаратный адаптер |
| Станция Миди | Не проверено | Иная схема сегментов | Требуется аппаратный адаптер |
| Станция 2 (`yandexstation_2`) | AirPlay 2, ARMhf receiver / AArch64 supervisor | Не требуется для аудио | Общий ALSA `plug:dmix_spk`, Алиса сохраняется |
| Мини 3 Про (`yandexmini_3_pro`) | AirPlay 2, AArch64 | Не требуется для аудио | Общий ALSA `speakers`, Алиса сохраняется |
| Остальные Станции | Не проверено | Возможности зависят от модели | Требуется исследование модели |

`plugin.toml` перечисляет только поддерживаемые model ID. Конкретные ABI, PCM и аппаратные требования проверяются в модельных профилях; Plum сохраняет обязательные clock/RGB-проверки. Не снимайте ограничения ради установки на неизвестную модель.

## Установка готовой сборки (Лайт 2)

Для Станции 2/Мини 3 Про используйте [отдельную инструкцию миграции](docs/SHARED_MODELS.md) и соответствующий модели архив по [AIRPLAY2.md](docs/AIRPLAY2.md). Архив `assets/station-airplay-1.1.5.yap` ниже — прежний релиз только для Plum.

1. Установите [YAM](https://github.com/nyakokitsu/yam) по официальной инструкции. Клиент `yam` запускается **на компьютере**, `yamd` — на Станции.
2. При необходимости подготовьте аудиоокружение устройства по [инструкции для Лайт 2](docs/PLUM.md). Скрипты подготовки изменяют системную конфигурацию и не запускаются автоматически.
3. Установите [готовый `.yap`](assets/station-airplay-1.1.5.yap) средствами YAM:

   ```sh
   yam install assets/station-airplay-1.1.5.yap
   yam enable station-airplay
   yam ps
   ```

4. Найдите в меню AirPlay устройство **`Я.Станция`**. Устройство и компьютер/телефон должны быть в сети, допускающей mDNS.

> Существующий независимый AirPlay-сервис или голосовой сервис колонки может занимать аудиоустройство/сетевые порты. Не запускайте две реализации одновременно. При любых ошибках сначала ознакомьтесь с [диагностикой](docs/TROUBLESHOOTING.md).

## Сборка из исходников

Для Go-супервизора требуется Go 1.23+; для упаковки — Python 3.8+. Полная сборка обеих архитектур и namespace helper: [source/BUILD.md](source/BUILD.md). **Упакованные ARMhf-бинарники сторонних программ уже присутствуют в `bin/` и `lib/`; их сборка из исходников здесь не автоматизирована.**

```sh
cd source
go test ./...
go vet ./...
GOOS=linux GOARCH=arm GOARM=7 CGO_ENABLED=0 go build -trimpath -ldflags='-s -w' -o ../bin/station-airplay .
cd ..
./scripts/package.sh
```

Архив будет создан в `dist/station-airplay-1.3.0.yap`. Перед публикацией проверьте зависимости и происхождение бинарников: [THIRD_PARTY.md](docs/THIRD_PARTY.md).

## Как это устроено

AirPlay-клиент → Shairport Sync → ALSA-выход + PCM FIFO → Go-сервис → YAM Runtime API → дисплей / RGB. Отдельно Avahi публикует сервис по mDNS, а NQPTP участвует в синхронизации AirPlay 2. Никакие аппаратные GPIO/LED-регистры плагин напрямую не изменяет.
